# Chat_bot_JR

Telegram чат-бот с интеграцией ChatGPT, переводчиком, викториной и другими возможностями.

## 📦 Возможности бота

- 🎲 Случайный факт
- 💬 Общение с AI (ChatGPT)
- 🌟 Общение с "знаменитостью" (бот отвечает в стиле выбранного персонажа)
- 🧠 Викторина (Quiz)
- 🌐 Голосовой и текстовый перевод
- 🏃 Подсчёт БЖУ и калорий из продуктов


## Как развернуть бота

1. Клонируй репозиторий
    git clone https://github.com/ArtiomLevitchii/Chat_bot_JR.git
2. Создай .env файл и внеси свои ключи по примеру .env.example
3. Установи внешние библиотеки pip install -r  из файла requirements.txt
4. Запусти бота   python main.py
